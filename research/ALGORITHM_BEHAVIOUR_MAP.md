# Algorithm-to-behaviour map of the 41 algorithms

Generated by `python -m research.algorithm_map` from the pipeline's own registry; do not edit by hand. Research document 8.2 warns against reading a whole-architecture result as proof of 41 algorithms at once:
this map says, per algorithm, how it could change an episode at all and what removing it would show.

41 algorithms (44 registry entries: ALGO-06, ALGO-10 and ALGO-34 have two roles each). Direct in the loop: 5 (ALGO-01, ALGO-04, ALGO-07, ALGO-21, ALGO-25). Pre-episode advice stages: 25. Post-episode record/verify/learn stages: 13.

What this means for a test. For an `advice` algorithm the only road to a decision is a model that READS the advice line in its prompt, so a scripted model cannot show an effect and a live test needs a model that reads and uses it. A `record` algorithm acts after the answer and cannot change the decisions of the episode it follows. Only the `direct` ones have a removal switch that changes the loop itself.
