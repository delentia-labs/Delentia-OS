## How many runs make a claim

Zero failures in n runs gives a one-sided 95% lower bound of 0.05^(1/n): 5 runs -> 0.55 (a screen, not a claim), 14 runs -> 0.81 (supports 'at least 80%'), 29 runs -> 0.90 (supports 'at least 90%'). One failure in the 14 needs more runs, not a smaller claim written afterwards. A claim for all 12 workflows is a claim per workflow: it is never averaged across them.

## What this does not give

A workflow is confirmed only when a capable language model has run it live the stated number of times and the oracle (not the agent) says it passed. Nothing here has been run live with a capable model yet.
