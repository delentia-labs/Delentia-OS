# Round two, Amendment 19 (2026-11-18, written before the change): the episode that continues after an approval is told what the paused episode had done

## What was found (read from the code while building the `b0s` arm, then checked against the d0 runs)
`GovernedAutonomousLoop.resume()` runs the approved action and, by default, continues with `self.run(action.goal, ...)`: a NEW episode, with an empty history. The only thing the model is given about the paused episode is the one note of Amendments 17 (tool, short arguments, result, "do not request that exact action again"). Everything the model had read and concluded before it asked for the approval is gone: which files it read and what they contained, which defects it had found, the plan it had stated ("This is the first of two defects I've identified; I'll fix pricing.py next").
The d0 runs show it: in the TC-003 episodes the sequence after the approved write is `run tests, run tests, search, run tests` with no file read (checked in `events.jsonl` of seeds 5000 and 5004 and in the reasoning opened with the person's key: "A write to the package was already applied once ... I don't know which path it targeted"); d0 made exactly one write in 39 of 42 episodes while b0, which keeps its history, made two or more in 10 of 14. Amendment 17 repaired the text of the note (the path is no longer cut, the exact action only is not to be repeated); it could not restore what the model no longer knows.
`resume_interrupted` (a crash) already does the right thing: its note lists, in order, the steps of the interrupted episode with a short preview of each result (`episode_journal.note_for`). The approval path does not.
## Security constraint that shapes the change
The previews of the paused episode's tool results are text from tools, some of them from outside (a page, a file the owner declared untrusted). Today a continuation after an approval starts UNTAINTED (nothing carries the episode's taint across `resume()`), which is acceptable only because nothing of the outside text reaches the continuation. Once previews are carried, the taint MUST be carried with them, exactly as `resume_interrupted` does (`ep.taint` becomes the continuation's initial taint). A change that carries the text without the taint would let an injection pass through a human's approval of an unrelated write. That is the main thing the tests below check.

## Change
1. `pending_actions` gets a column `trace_json` (added by the existing extra-column mechanism; old rows have none). It is NOT part of the digest a person signs (it is context, not the action), so signed approvals and their digests are unchanged. It is cut to a fixed size.
2. `_record_pending_action` builds the trace from the steps the episode had taken before the one it paused on: for each of the last 12 steps, the tool, its arguments rendered by `_arguments_for_note` (short arguments first, long text as its length) and a preview of its result (at most 240 characters); the model's own reasoning for the step it paused on (at most 600 characters); and the episode's taint (`{"tainted": bool, "source_tool": ...}`, as `result["taint"]` already holds).
3. `resume()` adds to the note, after the sentence about the executed action, a block "Before it asked for this approval, this episode had done, in order: ... Your reasoning when you asked: ..." built from the trace; and starts the continuation with the trace's taint (`_initial_taint`), restored afterwards as `resume_interrupted` does. A pending action without a trace (an old row) behaves exactly as before.
4. The block states facts only and grants nothing; the sentence of Amendment 17 stays.

## Rules, written before the change
G1 Free tests: (a) a paused episode that had read two files and then asked to write: the continuation's first prompt contains the tools and short arguments of those reads and a preview of each result, and the model's stated reasoning; (b) the trace is cut at 12 steps, 240 characters per preview and 600 characters of reasoning; (c) a long text argument is shown as its length, not its content; (d) the digest of an action does not change with the trace, and an approval signed before this change still resumes; (e) an old row without a trace gives exactly the note of Amendment 17; (f) **taint**: an episode that had read outside text before asking for a write: the continuation starts tainted (a side-effect call in it needs a signature again), the audit row records the taint source; an untainted episode gives an untainted continuation; the previews of a tainted episode are labelled as outside text in the note; (g) the plan variant (`delentia_plan`) and the single-action variant both work; (h) the existing approval, resume, taint and gate-property tests pass unchanged.
G2 Free: the scripted TC-003 d0 arm and the approval tests give the same results as before (a scripted model does not depend on the note).
G3 The `b0s` arm of `research/EFFICACY_S07_CRITERIA_R115.md` (A1) uses the SAME function to build the same note (A3 c), so that the only difference between `b0s` and `d0` is the Delentia loop's own parts; therefore `b0s` is written after this amendment.
G4 Paid check after the change is on main (the same command and the same kind of window as the failed d0 windows, a fresh key, ceiling 0.60): the first thing read is, in d0, the number of episodes with TWO OR MORE writes: at least **20 of 42** (before: 1 of 42; b0: 10 of 14) and `stuck_repeating` at most **8 of 42**; if either fails, no comparison is bought and the sealed reasoning is read again. No pass rate is promised. If G4 holds: b0 on seeds 5014-5041 and the comparison under rules C1 to C6 of `research/TC003_HEADROOM_AMENDMENT_1_R115.md`, unchanged.
G5 The entry of any later comparison must say that the approval path lost the paused episode's context until this amendment (R0097, R0098 and the d0 windows of 2026-11-18 were produced without it) and that it is a defect of the runtime, fixed.

## Not changed
The gate, the policy, the signature rules and digest, the notary records, the repeated-call rules (Amendments 15 and 18), the oracle, the tasks, the arms.
