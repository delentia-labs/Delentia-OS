# ร่างข้อความ (ไม่ได้ส่งแทนใคร: คุณตรวจ แก้ และส่งเอง)

ใช้ได้เมื่อ **เจ้าของรันเดโมสำเร็จด้วยตัวเองอย่างน้อยหนึ่งครั้ง** และมีผลจริงให้แนบ ยังไม่ควรส่งก่อนนั้น ทุกข้อความขอสิ่งเล็กที่คนช่วยได้ทันที ไม่ขอให้เชื่อสถาปัตยกรรมทั้งหมด
กติกาตรวจก่อนโพสต์: (1) คำกล่าวอ้างทุกคำต้องตรงกับ `research/claims.csv` และผลที่แนบ (2) ไม่ใส่คำว่า secure, guaranteed, production-ready, autonomous ถ้าไม่มีหลักฐานเฉพาะข้อนั้น
(3) ตัวเลขต้องมาจากไฟล์ผลของเดโม ไม่ใช่จากความจำ (4) แปลอังกฤษด้วย AI แล้วแปลกลับเป็นไทยเทียบความหมาย ตรวจชื่อ/ตัวเลข/สถานะ "มีแล้ว/ยังไม่มี" ด้วยตัวเอง

## A. โพสต์ชุมชนนักพัฒนาไทย (Facebook/Discord/LINE)

> สวัสดีครับ ผม [ชื่อของคุณ] เป็นคนทำโปรเจกต์ Delentia คนเดียว เป็น agent runtime ทดลองที่ให้ AI ใช้เครื่องมือจริง แต่ต้องรอคนเซ็นก่อนทำสิ่งที่เปลี่ยนไฟล์หรือส่งข้อมูลออก
> ตอนนี้มีเดโมหนึ่งงาน: ให้ agent อ่านใบเสนอราคาสังเคราะห์ 3 ใบ ทำตารางเทียบ และสรุปเจ้าที่ไม่เกินงบ โดยห้ามแก้ไฟล์ต้นฉบับ ระบบพิมพ์ทั้งขั้นตอน ผลตรวจ และบอกตรงๆ เมื่อทำไม่ผ่าน
> ผมสนทนาภาษาอังกฤษไม่ได้ ขอรับ feedback เป็นข้อความครับ
> **ขอความช่วยเหลือเล็กๆ:** มีใครใช้ Windows และพอมีเวลา 15 นาที ช่วยลองทำตามคู่มือ (`docs/demo/QUICKSTART_TH.md`) แล้วบอกว่าติดตรงไหนบ้างไหมครับ ไม่ต้องเข้าใจสถาปัตยกรรมทั้งหมด
> สถานะ: ทดลอง ยังไม่ใช่ของพร้อมใช้งานจริง ขอบเขตที่ทดสอบแล้ว/ยังไม่ได้ทดสอบเขียนไว้ท้ายคู่มือครับ [ลิงก์ release]

## C. ย่อหน้าบนสุดของ README (ไทย/อังกฤษ)

> **Delentia** is an experimental agent runtime that I build alone. An agent can use real tools, but anything that changes a file or sends data out waits for a human signature, and every step leaves a record.
> Today it has **one** demo you can run and check yourself (quotes comparison, Thai-language goal). It has been tested with a scripted model and with a small local model, and it does not yet pass the demo with that small model. It has not been run with a strong tool-calling model.
> I am looking for people to try the 15-minute demo and tell me where it breaks. I can read and answer in Thai or in writing; I cannot hold a live English conversation.

## D. สคริปต์คลิป 60–90 วินาที (เสียงไทย ซับอังกฤษ)

1. (0–10 วิ) หน้าจอ: โฟลเดอร์ `quotes/` มีไฟล์ 3 ใบ พูด: "ผมให้ agent อ่านใบเสนอราคา 3 ใบ ทำตารางเทียบ และบอกว่าเจ้าไหนไม่เกินงบ 15,000 บาท ห้ามแก้ไฟล์ ห้ามส่งอะไรออกไป"
2. (10–35 วิ) พิมพ์ `delentia demo run compare` แสดงเส้นทางที่ agent อ่านไฟล์ (ถ้ารอนาน บอกในคลิปว่าตัดเวลารอ)
3. (35–50 วิ) หน้าผลลัพธ์: ตาราง, ผลตรวจกับเฉลย, "ไฟล์ต้นฉบับไม่ถูกแก้", audit chain ครบ
4. (50–70 วิ) `delentia demo run edit` → ระบบหยุดรอลายเซ็น แสดงว่าไฟล์ยังไม่เปลี่ยน → `demo approve` → เปลี่ยน
5. (70–90 วิ) ข้อจำกัดบนหน้าจอ: "ทดลอง · ทดสอบกับโมเดลนี้เท่านั้น · ยังไม่ผ่านกับโมเดลเล็กในเครื่อง" + ที่ขอความช่วย
ต้องใช้ผลจริงที่รันจากสถานะเริ่มต้น; ถ้ามีรอบที่ล้มให้แสดงหนึ่งรอบด้วย (benchmark สาธารณะต้องรวมรอบที่ล้ม)
