# เปิด Desk (หน้าเว็บของ agent) ด้วยการดับเบิลคลิก ไม่ต้องเขียนโค้ด

สำหรับเจ้าของที่รัน host บนเครื่องตัวเอง (`scripts/local_host.py`) ไม่ต้องเปิด terminal ไม่ต้องรู้จัก token

## ใช้งาน

1. ดับเบิลคลิก **`OPEN_DESK.bat`** (อยู่ที่โฟลเดอร์ `Delentia` ระดับเดียวกับ `START_DAEMON.bat`) จะเปิดหน้าต่างดำ เขียนสามขั้นให้ดู:
   - `1/3` ตรวจ host ถ้าไม่ตอบ จะสั่งเริ่มให้ (ประมาณ 20 วินาที)
   - `2/3` ตรวจว่าหน้า Desk ถูก build แล้ว ถ้ายังไม่เคย จะ build ให้ (ครั้งแรกไม่กี่นาที ครั้งต่อไปข้าม) ต้องมี Node.js 20 ขึ้นไป
   - `3/3` เปิดตัวเสิร์ฟที่ `http://127.0.0.1:3010` แล้วเปิดเบราว์เซอร์ให้
2. ใช้ Desk ได้เลย ไม่ต้องกรอก token ที่หน้า Settings
3. เลิกใช้: ปิดหน้าต่างดำ (หรือกด Ctrl+C) host ยังทำงานต่อ เปิดใหม่เมื่อไรก็ได้

**ทำทางลัดบน Desktop:** คลิกขวาที่ `OPEN_DESK.bat` เลือก Send to → Desktop (create shortcut)

**หลังอัปเดตโค้ด** ให้ build หน้าใหม่: `OPEN_DESK.bat --build`

## มันทำงานอย่างไร (และไม่ใส่ token ไว้ที่ไหน)

- ตัวเสิร์ฟอยู่ที่ `127.0.0.1` เท่านั้น คนบนเครือข่ายเดียวกันเข้าไม่ได้
- หน้า Desk ขอที่อยู่ของ host และ token จากเส้นทางเดียว `/__delentia_local.json` ของตัวเสิร์ฟนั้น token **ไม่อยู่ใน URL** (URL จะติดประวัติเบราว์เซอร์) และ **ไม่ถูกเก็บลงดิสก์** หน้าเว็บถือไว้ในหน่วยความจำจนปิดแท็บ (ที่เก็บของเบราว์เซอร์มีแค่ที่อยู่ host)
- กันการหลอกสองแบบ: คำขอที่ระบุชื่อ Host ไม่ใช่เครื่องนี้ถูกปฏิเสธ (DNS rebinding) และคำขอ token จากเว็บไซต์อื่นถูกปฏิเสธ
- token อ่านจาก `%USERPROFILE%\delentia-host\api_token.txt` ที่ host สร้างไว้เอง ตัวเปิดไม่พิมพ์และไม่เขียน token ที่ไหน

## ถ้าติดขัด

| อาการ | สาเหตุ | ทางแก้ |
|---|---|---|
| `No host found at ...` | ยังไม่เคยสร้าง host | `python scripts\local_host.py init` แล้ว `start` |
| `the host did not come up` | host เริ่มไม่ขึ้น | ดู `%USERPROFILE%\delentia-host\logs\server.log` |
| `npm was not found` | ไม่มี Node.js | ติดตั้ง Node.js 20+ จาก nodejs.org |
| `the build failed` | build พัง | ข้อความบรรทัดบนบอกสาเหตุ ส่งให้ผู้ดูแล; host ไม่ถูกแตะ |
| `port 3010 is busy` | เปิด Desk ซ้อน | ปิดหน้าต่างเก่า หรือ `OPEN_DESK.bat --port 3011` |
| หน้าเปิดแต่ขึ้น 401 / ไม่มีข้อมูล | ไม่มีไฟล์ token | เปิด Settings ในหน้า Desk แล้ววาง token ของ host เอง |

## ขอบเขต (ซื่อตรง)

- นี่คือทางเข้าของ **เจ้าของบนเครื่องของตัวเอง** ไม่ใช่ทางเข้าของคนนอก คนนอกต้องมี token ของตัวเอง (`delentia tokens create <ชื่อ>`) และเข้าผ่านหน้า Desk ที่ host เสิร์ฟให้ ซึ่งยังไม่มี: แผนคือให้ host เสิร์ฟหน้า Desk เองหลัง proxy พร้อมหน้าล็อกอิน (ดูเอกสาร Round 92)
- ทดสอบแล้วกับ backend ทดสอบ 2 ตัว (ไม่มีและมี token บังคับ) และไม่ได้ทดสอบกับ host จริงของเจ้าของ (เพราะต้องอ่านไฟล์ token จริง)
- ยังไม่ได้ห่อเป็นแอปติดตั้ง (`.exe`/Tauri) ซึ่งเป็นขั้นถัดไปถ้าต้องการแจกให้คนอื่น
