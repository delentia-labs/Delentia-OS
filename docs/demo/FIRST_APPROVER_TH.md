# ตั้งผู้อนุมัติคนแรกของคุณ (ไม่ต้องสร้างกุญแจเอง)

คู่มือนี้สำหรับครั้งแรกที่ติดตั้ง Delentia บนเครื่องของคุณ ใช้เวลาประมาณ 3 นาที ไม่ต้องรู้เรื่องกุญแจหรือการเข้ารหัส

## ทำไมต้องมี "ผู้อนุมัติ"

Delentia ทำงานได้เองหลายอย่าง แต่งานที่เสี่ยงจริง (ลบไฟล์ ส่งข้อมูลออกนอกเครื่อง เงิน เผยแพร่ แก้สิทธิ์ แผนหลายขั้น) จะ **หยุดรอคนตัดสินใจเสมอ** คนนั้นคือคุณ ระบบต้องรู้ว่า "คุณ" คือใคร เมื่อใหม่ ๆ ยังไม่มีใครเลย งานเสี่ยงจึงรอไปตลอด (ปลอดภัยไว้ก่อน แต่ใช้งานไม่ได้) ขั้นตอนนี้คือการบอกระบบว่า "เครื่องนี้ และ Windows Hello ของฉัน คือผู้อนุมัติ"

## ทำไมไม่ให้หน้าเว็บสร้างให้เลย

ถ้าหน้าเว็บสร้างผู้อนุมัติคนแรกได้เอง โปรแกรมอื่นในเครื่อง (รวมถึงเอเจนต์เอง) ก็ทำได้เหมือนกัน และจะอนุมัติงานของตัวเอง ซึ่งผิดหลักที่ว่า "คนเป็นผู้ตัดสิน" ระบบจึงใช้ **รหัสครั้งเดียว** ที่ปรากฏเฉพาะในหน้าต่างเทอร์มินัลที่คุณเปิดเอง คนอื่นหรือโปรแกรมที่แค่อ่านหน้าเว็บไม่เห็นรหัสนี้

## ขั้นตอน (ติดตั้งด้วยตัวติดตั้ง Windows)

1. เปิดเมนู Start พิมพ์ **Delentia** เลือก **Delentia** (ไอคอนสีเขียวมีตา) รอสักครู่ เบราว์เซอร์จะเปิดหน้า Delentia
2. ที่หน้าแรก (สถานะ) จะเห็นกล่อง **"เริ่มต้นใช้งาน"** ขึ้นว่า "ยังไม่มีใครอนุมัติงานได้" ไปที่ **ตั้งค่า** (เมนูซ้าย)
3. เปิดเทอร์มินัล: กดปุ่ม Windows พิมพ์ `cmd` กด Enter แล้วพิมพ์

   ```
   "%LOCALAPPDATA%\Programs\Delentia\python\python.exe" -m rct_control_plane.cli approvals first-device-code
   ```

   (ถ้าติดตั้งด้วย pip ให้พิมพ์สั้น ๆ ว่า `delentia approvals first-device-code`)
4. จะได้รหัสแบบ `K7QM-4X2P` ใช้ได้ **10 นาที ลองได้ 5 ครั้ง ใช้ได้ครั้งเดียว**
5. กลับมาที่หน้า ตั้งค่า → ส่วน **อุปกรณ์ยืนยัน** จะมีกรอบสีเหลืองอธิบายขั้นตอนเดียวกัน พิมพ์ **ชื่อเครื่อง** (เช่น "โน้ตบุ๊กของฉัน") และ **รหัส** แล้วกด **เพิ่มเครื่องนี้**
6. Windows Hello จะถามตัวคุณ (ใบหน้า ลายนิ้วมือ หรือ PIN) ยืนยัน
7. เสร็จ ข้อความบอกว่า "เครื่องนี้เป็นผู้อนุมัติคนแรกแล้ว" แผงเริ่มต้นใช้งานจะหายไป

## ทดลองอนุมัติ 1 ครั้ง

1. ไปที่ **แชต** กดตัวอย่าง "ตรวจว่าบันทึกการทำงานของระบบยังสมบูรณ์ไหม" แล้วกด Enter (งานนี้ปลอดภัย ไม่ถามอะไร)
2. สั่งงานที่เสี่ยง เช่น "ลบไฟล์ x.txt ในโฟลเดอร์ทดสอบ" งานจะหยุดและไปปรากฏที่หน้า **อนุมัติ**
3. อ่านรายละเอียด แล้วกด **อนุมัติด้วยเครื่องนี้** (หรือ **ปฏิเสธด้วยเครื่องนี้**) Windows Hello ถาม ยืนยัน
4. ดูผลที่หน้า **เซสชัน**

## ถ้ามีอะไรผิดปกติ

| อาการ | ทำอย่างไร |
|---|---|
| บอกว่า "someone can already approve here" | มีผู้อนุมัติแล้ว ไม่ต้องใช้รหัส เพิ่มเครื่องถัดไปที่หน้า ตั้งค่า แล้วให้ผู้อนุมัติเดิมเซ็นรับรอง (ดู `APPROVE_WITH_DEVICE_TH.md`) |
| "that code is not right (N tries left)" | พิมพ์ผิด ลองใหม่ (ไม่มี 0/1/O/I/L ในรหัส เพื่อไม่ให้สับสน) ครบ 5 ครั้งรหัสถูกยกเลิก ขอรหัสใหม่ด้วยคำสั่งเดิม |
| "there is no live code" | เกิน 10 นาทีหรือยังไม่ได้ขอรหัส พิมพ์คำสั่งในข้อ 3 อีกครั้ง |
| ปุ่ม เพิ่มเครื่องนี้ กดไม่ได้ มีข้อความสีเหลือง | เปิดหน้าเว็บด้วยเลข `127.0.0.1` ให้เปิด `http://localhost:3010` (เมนู Start → Delentia เปิดให้ถูกอยู่แล้ว) |
| "this command is for the person at the keyboard" | คำสั่งนี้ไม่ทำงานเมื่อถูกเรียกโดยเอเจนต์ ตั้งใจให้เป็นอย่างนั้น เปิดเทอร์มินัลเองแล้วพิมพ์ |
| ไม่มี Windows Hello | ตั้งค่า Windows → บัญชี → ตัวเลือกการลงชื่อเข้าใช้ เปิด PIN หรือลายนิ้วมืออย่างใดอย่างหนึ่ง |

## ความปลอดภัย: สิ่งที่รหัสนี้ทำและไม่ทำ

* รหัสใช้ได้ **เฉพาะตอนที่ยังไม่มีผู้อนุมัติเลย** พอมีคนแรกแล้ว คำสั่งขอรหัสปฏิเสธ และรหัสเก่าใช้ไม่ได้
* ระบบเก็บเฉพาะค่าแฮชของรหัส ไม่เก็บรหัสจริง
* เอเจนต์ที่ทำงานในเครื่องคุณรันคำสั่งนี้ไม่ได้ (ถูกบล็อกสองชั้น: ตัวคำสั่งปฏิเสธเมื่อรู้ว่ามาจากเอเจนต์ และตัวคัดกรองคำสั่งของเอเจนต์ปฏิเสธข้อความคำสั่งนี้) แต่ตรงไปตรงมา: นี่คือ "ปุ่มกันพลาด" ไม่ใช่กำแพงเหล็ก เพราะเอเจนต์รันในบัญชีผู้ใช้เดียวกับคุณ ความปลอดภัยจริงมาจากการที่ **รหัสปรากฏบนหน้าจอที่คุณมองเอง** และต้องผ่าน Windows Hello ที่ต้องมีคุณอยู่หน้าเครื่อง
* คนที่ลองเดารหัสได้ 5 ครั้ง (โอกาสราว 1 ใน 8 แสนล้านต่อครั้ง) แล้วรหัสถูกยกเลิก ผลข้างเคียง: คนที่เปิดหน้าเว็บได้ทำให้รหัสของคุณใช้ไม่ได้ได้ (คุณขอใหม่ได้)

## ต่อไปทำอะไร

* เพิ่มเครื่องอื่น (เช่น มือถือ) ที่หน้า ตั้งค่า เครื่องที่สองต้องให้ **เครื่องแรกหรือกุญแจผู้อนุมัติ** เซ็นรับรอง
* อ่าน `APPROVE_WITH_DEVICE_TH.md` เรื่องการอนุมัติ การถอนสิทธิ์เครื่องที่หาย และข้อจำกัด
* ตั้งกฎของคุณเองว่างานแบบไหนต้องขออนุมัติ: หน้า **FDIA / นโยบาย** (โหมด Advanced)
