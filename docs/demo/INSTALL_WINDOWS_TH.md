# ติดตั้ง Delentia บน Windows ด้วยการดับเบิลคลิก

ไฟล์ติดตั้งชื่อ `Delentia-Setup-<เวอร์ชัน>.exe` ใช้เหมือนโปรแกรมทั่วไป: ดับเบิลคลิก กด Next จนจบ

**สถานะตรงไปตรงมา:** สคริปต์และไฟล์ทั้งหมดที่ใช้สร้างตัวติดตั้งอยู่ใน `installer/windows/` และทดสอบส่วนที่ทดสอบได้แล้ว แต่ **ยังไม่เคยสร้างไฟล์ `.exe` จริง** เพราะต้องมีโปรแกรมสร้างตัวติดตั้ง (Inno Setup) และ Python ฉบับพกพา ซึ่งต้องดาวน์โหลดและรอการอนุญาตของเจ้าของ (ดูหัวข้อ "สร้างตัวติดตั้ง") ส่วนด้านล่างจึงแบ่งเป็น "สำหรับผู้ใช้" (เมื่อมีไฟล์ให้ดาวน์โหลดแล้ว) และ "สำหรับผู้สร้างไฟล์"

## สำหรับผู้ใช้

### ติดตั้ง
1. ดับเบิลคลิก `Delentia-Setup-<เวอร์ชัน>.exe` (ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ ติดตั้งให้เฉพาะบัญชีของคุณ)
2. Windows อาจขึ้นหน้าต่าง "Windows protected your PC" (SmartScreen) เพราะไฟล์ยังไม่ได้ลงนามรหัสโปรแกรม (code signing) กด **More info → Run anyway** ถ้าคุณโหลดจากหน้าปล่อยเวอร์ชันอย่างเป็นทางการ และตรวจ SHA-256 ตรงกับที่ประกาศ
3. กด Next ตามขั้นตอน เลือกได้ว่าจะวางไอคอนบนเดสก์ท็อปหรือไม่
4. ตัวติดตั้งคัดลอกไฟล์ แล้วดาวน์โหลดและติดตั้งส่วนประกอบที่ Delentia ต้องใช้ **ต้องต่ออินเทอร์เน็ต ใช้เวลา 3-10 นาที** ถ้าล้มเหลวจะมีหน้าต่างบอกสาเหตุและที่เก็บบันทึก (`install.log`) ต่อเน็ตแล้วรันตัวติดตั้งซ้ำ
5. ติ๊ก "Open Delentia now" ที่หน้าสุดท้าย

### ใช้งาน
เมนู Start → **Delentia** มี 3 รายการ (ไอคอนสีเขียวมีตา):
* **Delentia** เปิดโปรแกรม (ไม่มีหน้าต่างดำ) แล้วเบราว์เซอร์เปิดหน้า Delentia ที่ `http://localhost:3010` ครั้งแรกรอราว 20-60 วินาที
* **Stop Delentia** ปิดสิ่งที่ Delentia เปิดไว้ (และเฉพาะสิ่งนั้น)
* **Update Delentia** ตรวจและติดตั้งเวอร์ชันใหม่ (ถามก่อนเสมอ) ดู `UPDATES_TH.md`

ครั้งแรกให้ทำ `FIRST_APPROVER_TH.md` (ตั้งผู้อนุมัติคนแรก) แล้วตั้งโมเดลที่หน้า **โมเดล**

### ข้อมูลของคุณอยู่ที่ไหน
* โปรแกรมอยู่ที่ `%LOCALAPPDATA%\Programs\Delentia`
* **ข้อมูลของคุณ** (ความจำ บันทึกการทำงาน กุญแจ การตั้งค่า) อยู่ที่ `%USERPROFILE%\.delentia` ตัวติดตั้งและตัวถอนการติดตั้ง **ไม่แตะโฟลเดอร์นี้เลย** การอัปเดตก็ไม่แตะ
* ไม่มีบริการที่ทำงานเองตอนเปิดเครื่อง ไม่มี start-up entry ไม่มีงานตั้งเวลาของระบบ Delentia ทำงานเมื่อคุณคลิกเท่านั้น

### ถอนการติดตั้ง
Settings → Apps → Delentia → Uninstall (หรือ Control Panel) ระบบสั่งหยุดสิ่งที่เปิดไว้แล้วลบโฟลเดอร์โปรแกรม ข้อมูลของคุณยังอยู่ (ลบเองได้ถ้าต้องการ ซึ่งจะลบความจำและบันทึกถาวร)

### ถ้าติดปัญหา
| อาการ | ทำอย่างไร |
|---|---|
| ตัวติดตั้งบอกว่าติดตั้งส่วนประกอบไม่สำเร็จ | ต่ออินเทอร์เน็ตแล้วรันซ้ำ ดูสาเหตุที่ `%LOCALAPPDATA%\Programs\Delentia\install.log` |
| คลิก Delentia แล้วมีหน้าต่างข้อความ "could not start" | ข้อความบอกสาเหตุ ส่วนมากพอร์ต 8000 หรือ 3010 ถูกโปรแกรมอื่นใช้ ปิดโปรแกรมนั้นหรือดู `%USERPROFILE%\.delentia\logs\serve.log` |
| เบราว์เซอร์เปิดแล้วหน้าว่างหรือขึ้นว่าเชื่อมต่อไม่ได้ | รอ 30 วินาทีแล้วรีเฟรช (ครั้งแรกช้า) ถ้ายังไม่ได้ดู `logs\serve.log` |
| Windows Defender/ไวรัสเตือน | ไฟล์ยังไม่ลงนามรหัสโปรแกรม ตรวจ SHA-256 กับที่ประกาศแล้วอนุญาต หรือรอรุ่นที่ลงนามแล้ว |

## สำหรับผู้สร้างไฟล์ติดตั้ง (เจ้าของ)

### ต้องดาวน์โหลด 3 อย่าง (รอการอนุญาตของคุณ)
| ไฟล์ | จาก | ขนาดโดยประมาณ | ใช้ทำอะไร |
|---|---|---|---|
| `python-3.12.10-embed-amd64.zip` | https://www.python.org/ftp/python/3.12.10/python-3.12.10-embed-amd64.zip | ~10 MB | Python ฉบับพกพาที่ติดไปกับโปรแกรม (3.12.10 คือรุ่น 3.12 สุดท้ายที่มีตัวติดตั้งไบนารี) |
| `get-pip.py` | https://bootstrap.pypa.io/get-pip.py | ~2.5 MB | สคริปต์ติดตั้ง pip ลงใน Python พกพา |
| Inno Setup 6 (`innosetup-6.x.exe`) | https://jrsoftware.org/isdl.php | ~5 MB | โปรแกรมที่สร้างไฟล์ `Setup.exe` (ติดตั้งลงเครื่องผู้สร้างเท่านั้น ไม่ได้อยู่ในตัวติดตั้งของผู้ใช้) |

สคริปต์ **ไม่ดาวน์โหลดอะไรเอง** รับเฉพาะไฟล์ที่คุณให้ และพิมพ์ SHA-256 ของแต่ละไฟล์ให้เทียบกับที่เว็บเจ้าของไฟล์ประกาศ (บันทึกใน `SOURCES.json` ในตัวติดตั้งด้วย)

### คำสั่งสร้าง
```
python installer/windows/build_installer.py --python-embed <python-3.12.10-embed-amd64.zip> --get-pip <get-pip.py>
```
* ไม่ระบุ `--wheel` จะ build wheel ให้เอง (รัน `scripts/package_desk.py` ก่อน เพื่อให้หน้าเว็บอยู่ในแพ็กเกจ ต้องมี Node.js 20+)
* `--stage-only` จัดไฟล์แล้วหยุด (ไม่ต้องมี Inno Setup) ใช้ตรวจโครงสร้าง
* `--offline-wheels` ใส่ไฟล์ส่วนประกอบทั้งหมดลงในตัวติดตั้ง ใหญ่ขึ้น (หลายร้อย MB) แต่ติดตั้งได้โดยไม่ต้องมีเน็ต
* ผลลัพธ์: `installer/windows/output/Delentia-Setup-<เวอร์ชัน>.exe` พร้อมพิมพ์ขนาดและ SHA-256

### ทดสอบก่อนแจกจริง (ควรทำบนเครื่อง Windows ที่สะอาด)
1. เครื่องที่ไม่มี Python (เครื่องเสมือนหรือบัญชีผู้ใช้ใหม่)
2. ดับเบิลคลิกติดตั้ง ดูว่า Start → Delentia เปิดหน้าเว็บ
3. ทำ `FIRST_APPROVER_TH.md` ครบ
4. ถอนการติดตั้ง ตรวจว่าโฟลเดอร์ `.delentia` ยังอยู่
5. ลงนามรหัสโปรแกรม (ใบรับรอง code signing) เมื่อจะแจกคนทั่วไป เพื่อไม่ให้ขึ้นคำเตือน SmartScreen

### สิ่งที่ตรวจแล้วและที่ยังไม่ตรวจ
* ตรวจแล้ว (เทสต์อัตโนมัติ): การจัดไฟล์ (Python พกพาตั้งค่า `._pth` ให้เห็น pip และแพ็กเกจ, wheel, สคริปต์ติดตั้ง), สคริปต์ Inno Setup (ติดตั้งแบบรายบัญชี ไม่มี start-up entry ไม่มีรีจิสทรี ไอคอน 3 รายการ ไม่แตะ `.delentia` แจ้งข้อผิดพลาดเป็นหน้าต่าง), ภาพโลโก้ขนาดถูกต้อง, คำสั่ง `launch` (เปิด/หาเจอซ้ำ/หยุดเฉพาะที่เปิด) รันจริงด้วย `pythonw` (ไม่มีหน้าต่างดำ)
* **ยังไม่ตรวจ:** การคอมไพล์ด้วย Inno Setup จริง, การติดตั้งบนเครื่องสะอาด, SmartScreen/ไวรัส, ขนาดและเวลาติดตั้งจริง

## ทำไมเป็น Inno Setup + Python พกพา ไม่ใช่ PyInstaller หรือ Tauri
* ระบบมีส่วนประกอบหนักและ import แบบไดนามิกจำนวนมาก (ตัวประมวลผล 41 อัลกอริทึม ฯลฯ) การรวมเป็น exe ก้อนเดียวด้วย PyInstaller เสี่ยงขาดโมดูลเงียบ ๆ และดีบักยาก
* Python พกพา + pip ติดตั้งแพ็กเกจจริงจาก PyPI ทำให้ตัวติดตั้งเล็ก และอัปเดตได้ด้วย `delentia update --apply` ทางเดียวกับผู้ใช้ pip
* แอปเดสก์ท็อป Tauri (`apps/gui/src-tauri`) มีไฟล์เตรียมไว้แต่ไอคอนเป็นภาพชั่วคราว และต้อง build ด้วย Rust + เครื่องมือของ Visual Studio ซึ่งเป็นงานอีกก้อน ไม่จำเป็นสำหรับการเปิดใช้งานทั่วไป
