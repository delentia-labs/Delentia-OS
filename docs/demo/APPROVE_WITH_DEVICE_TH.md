# อนุมัติงานเสี่ยงด้วยเครื่องของคุณ (Windows Hello) แทนการพิมพ์คำสั่ง

เขียนสำหรับคนที่ไม่เขียนโค้ด ทำครั้งเดียวต่อเครื่อง หลังจากนั้นอนุมัติงานได้ด้วยการกดปุ่มแล้วยืนยันหน้า/ลายนิ้วมือ/PIN

## อะไรเปลี่ยนไป และอะไรไม่เปลี่ยน

* **เปลี่ยน:** แทนที่จะเปิดเทอร์มินัลแล้วพิมพ์ `delentia approvals approve ...` ทุกครั้ง คุณกดปุ่ม **"อนุมัติด้วยเครื่องนี้"** ในหน้า อนุมัติ แล้ว Windows Hello ถามตัวคุณ กดครั้งเดียว ระบบอนุมัติและรันงานนั้นหนึ่งครั้ง
* **ไม่เปลี่ยน:** งานที่ปลอดภัยไม่ต้องอนุมัติเลย (ไม่มีปุ่ม "อนุมัติทุกอย่าง" และไม่มีปุ่มกดธรรมดา) การอนุมัติใช้กับงานที่เสี่ยงจริงเท่านั้น: ลบ ส่งออกนอก เงิน เผยแพร่ แผนหลายขั้น ทุกครั้งถูกบันทึกในบันทึกที่ตรวจสอบย้อนหลังได้ ว่าใครอนุมัติ ด้วยเครื่องไหน เมื่อไร และรันได้ครั้งเดียว
* กุญแจส่วนตัวของ Windows Hello **ไม่เคยออกจากเครื่อง** ระบบเก็บเฉพาะกุญแจสาธารณะ

## ก่อนเริ่ม (ตรวจ 3 อย่าง)

1. เปิด Windows Hello แล้ว: ตั้งค่า Windows → บัญชี → ตัวเลือกการลงชื่อเข้าใช้ → มีอย่างน้อยหนึ่งวิธี (หน้า ลายนิ้วมือ หรือ PIN)
2. มี **ผู้อนุมัติ** อยู่แล้วหนึ่งคน ถ้ายังไม่มีเลย (ครั้งแรกที่ติดตั้ง) ให้ทำ `FIRST_APPROVER_TH.md` ก่อน: ใช้รหัสครั้งเดียวจากเทอร์มินัล ไม่ต้องสร้างกุญแจเอง ถ้ามีกุญแจ approver อยู่แล้ว (ของคุณมี: `C:\Users\whale\.delentia\keys\architect.pem`) ข้ามได้ เหตุผลที่เครื่อง **ถัดไป** ต้องให้ผู้อนุมัติเดิม "รับรอง" ก่อน: ไม่ให้ใครก็ตามที่เข้าถึงหน้าเว็บเพิ่มเครื่องของตัวเองเป็นผู้อนุมัติได้เอง (เครื่องแรกที่ใช้รหัสครั้งเดียวใช้งานได้ทันที)
3. **เปิด Desk ที่ชื่อ `localhost` ไม่ใช่เลข `127.0.0.1`**: เบราว์เซอร์ไม่ให้ใช้ Windows Hello กับหน้าที่เปิดด้วยตัวเลข `OPEN_DESK.bat`, เมนู Start → Delentia และคำสั่ง `delentia desk` เปิดให้ถูกแล้ว ถ้าเปิดเอง ให้พิมพ์ `http://localhost:3010`

## เพิ่มเครื่องนี้ (ครั้งเดียว)

1. เปิด Desk → **ตั้งค่า** → ส่วน **อุปกรณ์ยืนยัน**
2. พิมพ์ชื่อเครื่อง (เช่น "โน้ตบุ๊กของฉัน") แล้วกด **เพิ่มเครื่องนี้** Windows Hello จะถาม ยืนยัน
3. เครื่องขึ้นสถานะ **"รอผู้อนุมัติเซ็นรับรอง"** (ยังใช้ไม่ได้ นี่คือด่านที่ตั้งใจไว้)
4. ดับเบิลคลิก `SIGN_PENDING.bat` ที่ `C:\Users\whale\Delentia` (หรือพิมพ์ `delentia approvals review --key <ไฟล์กุญแจผู้อนุมัติ>`) มันแสดงรายการที่รออยู่เป็นภาษาอ่านออก: ต้องเห็นบรรทัด *"this lets a device named 'โน้ตบุ๊กของฉัน' approve actions from now on"* ถ้าใช่ให้พิมพ์ `a` (approve) แล้ว Enter ถ้าคุณไม่ได้เพิ่มเครื่องเอง **พิมพ์ `r`** (reject) และถ้าไม่แน่ใจพิมพ์ `s` (skip) แล้วค่อยกลับมา
5. กลับมาที่หน้า ตั้งค่า กด **เปิดใช้** เครื่องขึ้นสถานะ **ใช้งานอยู่**

## อนุมัติงาน

1. เปิดหน้า **อนุมัติ** อ่านรายละเอียดให้ครบ (แผนหลายขั้นจะแสดงเป็นขั้นที่ 1, 2, 3 พร้อมชนิดของแต่ละขั้น)
2. กด **อนุมัติด้วยเครื่องนี้** → Windows Hello ถาม → ยืนยัน
3. ระบบอนุมัติและรันงานทันที หน้าจอขึ้นข้อความยืนยัน ดูผลที่หน้า **เซสชัน**
4. ไม่เห็นด้วย: กด **ปฏิเสธด้วยเครื่องนี้** งานนั้นจะไม่ถูกรัน

งานที่กำหนดว่าต้องมี 2 ลายเซ็น: เครื่องหนึ่งเครื่องเซ็นได้หนึ่งลายเซ็น ต้องใช้อีกเครื่อง (หรือกุญแจ approver อีกคน) เซ็นอีกครั้ง

## ถอนสิทธิ์ (เครื่องหาย / ไม่ใช้แล้ว)

หน้า ตั้งค่า → **ถอนสิทธิ์** ข้างชื่อเครื่อง เครื่องนั้นอนุมัติอะไรอีกไม่ได้ และงานที่มันเคยอนุมัติแต่ **ยังไม่ได้รัน** จะใช้ไม่ได้ทันที (ต้องขออนุมัติใหม่) ถอนสิทธิ์ทำได้เสมอ ไม่ต้องมีลายเซ็น

## ถ้ามีอะไรผิดปกติ

| อาการ | สาเหตุที่พบบ่อย | ทำอย่างไร |
|---|---|---|
| ปุ่มเพิ่มเครื่องกดไม่ได้ มีข้อความสีเหลือง | เปิดด้วย `127.0.0.1` หรือเบราว์เซอร์ไม่รองรับ | เปิดที่ `http://localhost:3010` |
| ขึ้น "ยกเลิก หรือหมดเวลา" | กดยกเลิก หรือรอนานเกิน 2 นาที | ไม่มีอะไรถูกบันทึก ลองใหม่ |
| ขึ้น "อุปกรณ์นี้ลงทะเบียนไว้แล้ว" | เครื่องนี้เคยเพิ่มแล้ว | ดูรายการในหน้า ตั้งค่า |
| ไม่เห็นปุ่ม "อนุมัติด้วยเครื่องนี้" | ยังไม่มีเครื่องที่ **ใช้งานอยู่** | ทำส่วน "เพิ่มเครื่องนี้" ให้ครบ จนสถานะเป็น ใช้งานอยู่ |
| ปุ่มกดแล้วบอกว่า "ไม่ได้รับอนุญาต" | งานนั้นต้องการบทบาท/ขอบเขตที่เครื่องนี้ไม่มี | ใช้กุญแจ approver หรือเครื่องที่มีบทบาทนั้น |

## ข้อจำกัดที่ต้องรู้ (ตรงไปตรงมา)

* เครื่องของคุณเซ็นยืนยัน **"รหัสของงาน"** (ลายนิ้วมือดิจิทัลของสิ่งที่จะทำ) ไม่ได้เซ็น "ข้อความที่เห็นบนจอ" ดังนั้นหน้าจอนี้ต้องเชื่อถือได้: เปิดที่ `localhost` ของเครื่องคุณเอง อ่านรายละเอียดก่อนกด และสำหรับงานเสี่ยงสูงสุดควรตั้งให้ต้องเซ็นสองคน
* ถ้าเปิดเครื่องทิ้งไว้ไม่ล็อกจอ คนที่นั่งหน้าเครื่องก็กดอนุมัติได้ (Windows Hello ถามตัวตนทุกครั้ง แต่ถ้าเป็นคุณที่เดินผ่านไปแล้วมีคนอื่นมานั่ง...)
* ถ้าบัญชี Microsoft ของคุณซิงก์ passkey ไปยังเครื่องอื่น ความปลอดภัยของมันเท่ากับบัญชีนั้น ระบบบันทึกว่า passkey ซิงก์ได้หรือไม่ (`backup_eligible`)
* ผู้เขียนทดสอบกับตัวจำลอง WebAuthn ในเบราว์เซอร์จริง (รูปแบบข้อมูลตรงตามมาตรฐาน ลายเซ็น ES256 และ RS256 ตรวจจริง) แต่ **ยังไม่ได้ทดสอบกับ Windows Hello จริงของคุณ** ถ้าเจออาการแปลก บอกอาการที่เห็น
