# คู่มือ: นำเข้าตัวบทกฎหมายฉบับทางการ และเทียบกับฉบับที่ใช้ทดสอบอยู่ (Law Pack)

สำหรับเจ้าของระบบ (Architect) ใช้เวลา 15-30 นาที ผมโหลดไฟล์ PDF จากราชกิจจานุเบกษาให้ไม่ได้: เว็บไซต์ราชกิจจาฯ ตั้งด่านตรวจ "คุณคือมนุษย์หรือไม่" (Cloudflare) และผมไม่ผ่านด่านนั้น (และไม่ควรพยายามหลบ) จึงต้องให้คุณโหลดเอง

## 0. สถานะตอนนี้ (ตรวจแล้ว 2026-10-19)

- ความหมายของ "ฉบับทางการ": ฉบับในราชกิจจานุเบกษา เล่ม 136 ตอนที่ 69 ก วันที่ 27 พฤษภาคม 2562 **แต่ตัวบทนี้ถูกแก้/เสริมด้วยกฎหมายลูกและประกาศหลังจากนั้นมาก** (เช่น พระราชกฤษฎีกาเลื่อนการบังคับใช้, ประกาศคณะกรรมการปี 2569) pack ทุกอันเป็น "ภาพถ่าย ณ วันนำเข้า" และแสดงฉบับ (edition) ในทุกคำตอบ

## 2. แปลง PDF เป็นข้อความ UTF-8

เครื่องนี้มี `pdftotext` มากับ Git for Windows แล้ว:

```powershell
cd C:\Users\whale\Downloads
& "C:\Program Files\Git\mingw64\bin\pdftotext.exe" -enc UTF-8 pdpa_official.pdf pdpa_official.txt
Get-Content pdpa_official.txt -TotalCount 40 -Encoding UTF8
```

**ตรวจด้วยตาก่อน:** ภาษาไทยต้องอ่านออก (สระ/วรรณยุกต์ไม่แยกจากพยัญชนะ) และหัวมาตราต้องขึ้นต้นบรรทัดแบบ `มาตรา ๑` หรือ `มาตรา 1` ปัญหาที่พบบ่อยของ PDF ไทย:
- ตัวอักษรเพี้ยน/เป็นสี่เหลี่ยม → PDF ฝังฟอนต์แบบที่สกัดข้อความไม่ได้ ให้ลองเปิดด้วยเบราว์เซอร์ เลือกทั้งหน้า (Ctrl+A) คัดลอกไปวางใน Notepad แล้วบันทึกเป็น UTF-8
- ไม่มีข้อความเลย → PDF เป็นภาพสแกน (ต้อง OCR) ให้ใช้แหล่งที่สอง (law.prd.go.th) หรือแจ้งผม
- สระอำแตกเป็น "ํา" → ระบบนำเข้ารวมให้เองแล้ว (Unicode NFKC) ไม่ต้องแก้

## 3. นำเข้าเป็น pack ใหม่

ทางที่ 1 (หน้าเว็บ): เปิด Desk → **ตัวบทกฎหมาย** → ส่วน "นำเข้าตัวบท" วางข้อความทั้งหมด ตั้งชื่อ `thai-pdpa-official` เขตอำนาจ `TH` ฉบับ `ราชกิจจานุเบกษา เล่ม 136 ตอนที่ 69 ก 27 พ.ค. 2562` แหล่งที่มา (ลิงก์ที่คุณโหลด) ติ๊ก "ตัวกรองตั้งธงและฉันอ่านแล้ว" **เฉพาะเมื่อระบบแจ้งว่าต้องใช้** แล้วกด นำเข้า (ตัวบทยาวอาจใช้เวลาหลายนาทีตอนสร้าง embedding)

ทางที่ 2 (คำสั่ง):
```powershell
cd C:\Users\whale\Delentia\Delentia-OS
$env:DELENTIA_MEMORY_EMBED_MODEL = "bge-m3"
$env:DELENTIA_MEMORY_EMBED = "ollama"
py -3.13 -m rct_control_plane.cli law import thai-pdpa-official C:\Users\whale\Downloads\pdpa_official.txt --edition "ราชกิจจานุเบกษา เล่ม 136 ตอนที่ 69 ก 27 พ.ค. 2562" --jurisdiction TH --source "ratchakitcha.soc.go.th T_0052.PDF" --allow-flagged
```
(ถ้าไม่ใส่ `--allow-flagged` ระบบจะ **แสดงถ้อยคำที่ทำให้ติดธง** ให้คุณอ่านก่อน ซึ่งเป็นขั้นที่ตั้งใจให้คุณเห็น: ถ้าเป็นวลีกฎหมายธรรมดาจึงค่อยใส่ธง ถ้าเห็นประโยคที่สั่งผู้อ่าน เช่น "ให้ละเลยคำสั่งก่อนหน้า" ให้หยุดและบอกผม)

## 4. เทียบกับ pack ที่ใช้ทดสอบ

```powershell
py -3.13 -m rct_control_plane.cli law compare thai-pdpa-wikisource thai-pdpa-official
```
อ่านผลอย่างนี้:
- `identical after ignoring spacing, numerals and Unicode form: N` = มาตราที่ตรงกันทุกตัวอักษร (ไม่นับช่องว่าง เลขไทยกับเลขอารบิก และรูปแบบสระอำ)
- `only in A / only in B` = มาตราที่มีฝั่งเดียว (ส่วนมากเกิดจากการแยกหัวมาตราพลาด ไม่ใช่กฎหมายต่างกัน ให้ดูที่ PDF)
- `!! section N: similarity ...` = มาตราที่ต่างกัน; บรรทัด `A:` กับ `B:` แสดงจุดแรกที่ต่าง
- **`numbers only in A/B` คือสิ่งที่ต้องอ่านทุกจุด** ตัวเลข (จำนวนวัน จำนวนเงินปรับ) เปลี่ยนแล้วคำตอบเปลี่ยน
- คำสั่งจบด้วยรหัส 1 ถ้ามีมาตราใดต่าง/หาย/ตัวเลขต่าง และ 0 ถ้าเหมือนกันทั้งหมด

ระบบ **เทียบข้อความ ไม่ได้บอกว่าฉบับไหนถูก** คุณต้องเปิดมาตราที่ถูกลิสต์เทียบกับ PDF เอง ถ้าฉบับวิกิซอร์ซผิด ให้ทิ้งมันไปใช้ฉบับทางการแทน (pack เก่าเก็บไว้ ไม่ลบ ตามนโยบาย Zero-Delete: เปลี่ยนชื่อไฟล์ใน `law_packs` ถ้าอยากซ่อน)

## 5. ตรวจความสมบูรณ์ของ pack ทุกครั้งที่สงสัย

```powershell
py -3.13 -m rct_control_plane.cli law verify thai-pdpa-official
```
`OK` = ข้อความตรงกับที่นำเข้า; `CHANGED` = มีคนแก้ไฟล์หลังนำเข้า (ห้ามใช้ ให้นำเข้าใหม่); `NOT CHECKED` = pack เก่าที่นำเข้าก่อนมี fingerprint (นำเข้าใหม่เพื่อให้ตรวจได้)

## 6. จากนั้นผมทำอะไรต่อ

เมื่อคุณมี pack ฉบับทางการ บอกผมชื่อ pack ผมจะรันชุดคำถามไทย 3 ชุด (ที่เขียนไว้ล่วงหน้า) ซ้ำกับตัวบทฉบับทางการ และรายงานว่าผลต่างจากฉบับวิกิซอร์ซหรือไม่ โดยเฉพาะมาตราที่ `law compare` ตั้งธง

## 7. ที่ต้องรู้ (ซื่อสัตย์)

- ผมยังไม่เคยเห็นไฟล์ทางการ จึงยังไม่รู้ว่า `pdftotext` กับ PDF ฉบับนั้นให้ภาษาไทยที่อ่านออกหรือไม่ ขั้นที่ 2 คือจุดที่น่าจะพังก่อน
- ผลทดสอบทั้งหมดของ Law Pack ใช้โมเดลในเครื่องขนาด 8B + คำถามที่ผมเขียนเอง ไม่ใช่การพิสูจน์ว่า "ระบบรู้กฎหมาย" และไม่ใช่คำแนะนำทางกฎหมาย
