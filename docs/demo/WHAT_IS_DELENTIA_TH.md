# Delentia คืออะไร (หนึ่งหน้า ไม่ใช้ศัพท์)

สถานะ: **ทดลอง (experimental)** เขียนจากสิ่งที่วัดได้จริงเท่านั้น ตัวเลขทุกตัวมีที่มาในไฟล์ `research/` ของโปรเจกต์

## ปัญหาที่มันพยายามแก้
เมื่อ AI เปลี่ยนจาก "ตอบคำถาม" เป็น "ลงมือทำ" (อ่านไฟล์ แก้ไฟล์ เปิดเว็บ ส่งข้อความ) คุณต้องการมากกว่าคำตอบที่ฟังดูฉลาด คุณต้องรู้ว่า
มันเข้าใจเป้าหมายอะไร มีสิทธิ์ทำอะไร จำสิ่งที่คุณสั่งไว้ได้ไหม และถ้ามันพลาด คุณตามรอยย้อนหลังได้ไหม

## Delentia คือ runtime ของ AI agent ที่มีชั้นความปลอดภัยอยู่ข้างใน ไม่ใช่ระบบปฏิบัติการ
ชื่อ "OS" ไม่ได้หมายถึง Windows หรือ Linux มันคือโปรแกรมที่รัน agent บนเครื่องของคุณเอง: ลูปการทำงาน เครื่องมือ ความจำ ทักษะ ตารางเวลา ช่องแชต และ agent ย่อย อยู่ข้างในทั้งหมด และ **ทุกงานผ่านด่านเดียวกัน** (ตรวจก่อน วางแผน ลงมือโดยขอลายเซ็นของคุณเมื่อสำคัญ ตรวจผล บันทึก เรียนรู้) สิ่งเดียวที่มันไม่ได้บรรจุไว้คือโมเดลภาษา ซึ่งจะเป็นโมเดลในเครื่องหรือบริการภายนอกก็ได้

## สิ่งที่มันทำให้คุณ (และพิสูจน์ได้ด้วยตัวเอง)
| สิ่งที่คุณได้ | ทำงานอย่างไร | ดูเองได้อย่างไร |
|---|---|---|
| **ถามก่อนทำสิ่งสำคัญ** | การแก้ไฟล์ รันคำสั่งที่ไม่ใช่การอ่านอย่างเดียว เปิดที่อยู่ที่คุณไม่ได้พิมพ์ ต้องรอ **ลายเซ็นของคุณ** (กุญแจอยู่กับคุณ ไม่ใช่กับ agent) | `demo run edit` หยุดรอ ไฟล์ยังไม่เปลี่ยน |
| **ไม่หลงเชื่อข้อความจากเว็บ/ไฟล์ที่ได้รับ** | ถ้า agent อ่านข้อความจากภายนอก การกระทำที่มีผลข้างเคียงต้องขอลายเซ็นเสมอ ไม่ว่าโมเดลจะถูกหลอกหรือไม่ | วัดกับโมเดลปลอมที่ยอมทำตามทุกคำสั่ง (23 กรณี): ใช้แค่พื้นความปลอดภัยในตัว ผลข้างเคียงรันได้ 18; ใช้นโยบายเริ่มต้นของเจ้าของ 3; เปิดกฎข้อความภายนอกด้วย 0 (งานที่ถูกต้อง 6 งานยังรันได้) เป็นโมเดลปลอม ไม่ใช่โมเดลจริง |
| **จำกฎของคุณข้ามครั้ง** | `delentia memory add --pin "ห้ามแก้ไฟล์ต้นฉบับ"` กฎจะถูกแสดงให้ agent **ทุกครั้ง** ไม่ว่างานคืออะไร | เปิดหน้า Memory / `delentia memory list` |
| **บันทึกที่ตรวจย้อนได้** | ทุกการกระทำอยู่ในโซ่ที่ถูกแก้ไม่ได้โดยไม่ถูกจับ (ผูกด้วยแฮชและลายเซ็น) | `delentia audit-chain verify` |
| **ลืมคนได้จริง** | คำสั่งลบคนหนึ่งคนทำลายกุญแจที่ปิดผนึกข้อความของเขา ไม่เหลือคำของเขาในไบต์ใดของฐานข้อมูล (สำหรับข้อความที่เขียนหลังเปิดการปิดผนึก; ข้อความเก่ากว่านั้นและฐานข้อมูล skill แยกไม่ถูกลบ ระบบรายงานให้) | `delentia memory erase-request` |
| **ภาษาไทย** | เรียกคืนความจำภาษาไทยด้วยโมเดลหลายภาษา (bge-m3): ถามเรียบเรียงใหม่แล้วเจอ 38 จาก 40 | `delentia memory calibrate --model bge-m3` |

## สิ่งที่มันยังทำไม่ได้ / ยังไม่พิสูจน์ (ตรง ๆ)
- **ยังไม่เคยรันกับโมเดลที่เก่งพอจะใช้เครื่องมือได้ดีจริง** โมเดลในเครื่องที่ลองยังเลือกเครื่องมือผิดบ่อย (ผลการทดสอบความปลอดภัยจึงมาจากโมเดลจำลองเป็นหลัก)
- **ยังไม่มีผู้ใช้ภายนอก** และยังไม่มีเซิร์ฟเวอร์สาธารณะ
- โซ่บันทึก "ตรวจย้อนได้" แต่**ยังไม่ใช่ "แก้ไขไม่ได้เลย"**: ผู้ที่ยึดเครื่องได้ทั้งเครื่องเขียนใหม่ได้ จนกว่าจะมีพยานภายนอก
- กฎที่ปักหมุด: แสดงสูงสุด 8 ข้อต่อครั้ง (ค่าเริ่มต้น เดิม 5 ข้อ กฎข้อที่หกเคยดันข้อเก่าสุดออกโดยไม่บอก จึงขยายเพดานและประกาศเมื่อมีการตัด) กฎที่ไม่ได้ปักหมุดต้องอาศัยการค้นด้วยความหมาย ซึ่งในการวัด agent เห็นกฎที่เกี่ยวข้องเพียง 29 จาก 40 ข้อ
- ภาษาอังกฤษด้วย bge-m3 ได้น้อยกว่า nomic เล็กน้อย (33 กับ 37 จาก 40)
