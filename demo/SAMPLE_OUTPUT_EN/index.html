    What the model-free demo prints in English (a real run)¶

    Produced by delentia demo init --lang en, delentia demo run compare --scripted, delentia demo run edit --scripted and delentia demo approve <id> --scripted on a machine with no model installed. --scripted replaces only the model; the files, tools, safety gate, signature check and audit log in these outputs are real. The dates and the approval id change on every run. The Thai version of the same run is SAMPLE_OUTPUT.md.

    1. delentia demo init --lang en¶

    Demo folder: ~/delentia-demo
Created: lang.txt, quotes/vendor_a.md, quotes/vendor_b.md, quotes/vendor_c.md, README_EN.md, keys/demo-approver.pem, keys/audit.pem, data/originals.json
Next: delentia demo run compare --scripted   (no model needed)   or   delentia model show, then   delentia demo run compare
